沙滩中央的冰淇淋摊

AI 时代创业的逻辑倒置：当投资人、创始人与人才都在追求个体利益最大化，为什么最后可能合成一场集体利益最小化。

胡凌冲 · 2026-07-30

这不是一篇创业指南。更像是我这几年走过、看过、也踩过之后，终于能说清楚的一点体感：AI 把造东西变便宜了，但围绕创业形成的那套融资与组织逻辑，还没有来得及倒过来。

一、套壳潮的坟场

最早那一拨 AI 创业热潮里，套壳大模型、prompt engineering、把聊天框换个皮肤的项目，都能拿到一笔不错的投资。模型能力每隔几个月就跳一次，演示效果足够惊艳。

现在回头看，那批项目基本死得差不多了。投资人也很正常地收紧了范围。原因并不神秘：如果你的护城河是一段 prompt，那么下一次模型发布，就是你的竞争对手。Claude Code 和 Codex 出来的那段时间，击碎了多少初创公司，不是因为它们忽然做错了什么，而是底层模型顺手把它们原来收费提供的能力吃进了基础设施。

模型升级并不是普通竞争者。普通竞争者还要理解产品、复制流程、争客户；模型厂商只要把能力往前推一格，你的产品边界就可能整块消失。太多团队把模型暂时不会做的那一点缝隙，当成了长期市场。

二、投资人的账本没变

项目死了一批，不代表硅谷式投资的账本变了。投资人仍然可以接受一百个项目里九十九个归零，只要剩下一个成为独角兽，就足够回本，甚至大赚一笔。这对单个 VC 来说完全理性：他买的不是一家安稳赚钱的小生意，而是一张可能改变某个行业的期权。

所以硅谷式创业本质上仍在比谁能讲一个好故事。不是说你不能踏踏实实做项目，而是故事不够大，就很难拿到支撑传统创业配置的投资。十倍、百倍的增长、平台与网络效应，总比“先解决一个真实的小问题，看看有没有人付钱”更符合这套账本。

问题不是讲故事本身。所有融资都需要描述未来。问题在于，当未来的故事先于今天的证据，团队会开始为故事组织现实，而不是用现实修改故事。

三、逻辑倒置：先烧钱，才产生“必须融资”

传统的创业叙事里，融资是为了生存：有团队要发工资，有场地要付租金，有管理、招聘和市场开支，所以公司必须不断拿到下一轮钱。但我后来越来越觉得，这里的因果关系经常是倒着的。

很多非具身智能、非机器人、非硬科技的团队，从 demo 到初期产品，从联系早期客户到验证需求，根本不需要先有一屋子员工。两三个有精力的创始人，加两三个 Claude 和 Codex 账户，已经可以把这段路走完。先搭团队和场地，才制造了巨大的生存开支；巨大的生存开支又证明融资不可或缺；拿到融资以后，扩张团队似乎又成了“钱必须花出去”的合理动作。

烧钱合理化了融资，融资又制造了更多烧钱。最后团队不是为了验证需求而存在，而是需求必须被证明足够宏大，才能让已有团队继续存在。一个本来应该两周证伪的假设，被几十个人的工资绑成了不能承认失败的战略方向。

四、产品常常只是“替代的幻想”

AI 让“产品”这个词变得更空虚了。大多数产品并不是凭空创造一片蓝海，而是在某个行业里想象一种对已有工作方式的替代。以前学校里很火的自动找工作 agent、dating agent，依赖的都是大模型能力，以及“原来的流程很麻烦，所以人们一定想把它交给 agent”这个推断。

但流程繁琐，不等于它需要被省略；即使需要省略，也不等于用户愿意用代理式的方式省略。拿找工作 agent 来说：它要实时抓到各个平台的岗位信息，先解决 API 和数据来源；要合法持续地拿数据，再解决平台条款和合规；要理解用户背景，再做匹配推荐；最后还要一键申请，并处理不同公司的表单、验证和反自动化机制。

这五环里，任何一环都可能把整件事证伪。数据源无法合法解决，不是“以后优化”的小问题，而是在技术上直接否定了这个产品的实现方式。用户不愿把求职判断交给 agent，也不是营销文案还不够好，而是需求假设错了。

所以需求的真伪，需要实际实现来核验。团队此时该做的，不是守着原故事继续烧，而是在只有两三个创始人、几个 Claude 和 Codex 账户的开支下，迅速 pivot，换一个需求重新验证。

支付，而不是支付意愿。
“如果有我愿意用”“做出来我可能会买”都不算验证。早期用户真的把钱付进来，才说明你碰到的不是礼貌、好奇或对新技术的兴奋，而是一项值得被解决的工作。

五、你最重要的技术成员，是 Claude 和 Codex

早期该有什么人，取决于你要退掉的最大风险是哪种。需求风险——东西好造、有没有人付钱不知道——验证工具是你和你的 Claude；技术风险——需求明摆着、造不造得出来不知道，比如机器人、火箭、新药——验证工具才是工程师。

套壳潮的荒谬正在于：人人做的都是需求风险型项目，却按技术风险型项目的配置去烧钱建团队——招了一屋子工程师，去验证一个不需要工程师就能证伪的需求。

在最开始，你最重要的技术成员就是 Claude 和 Codex，以及周围愿意使用初期产品的早期用户。可以有一个真正懂这个方向和行业的技术顾问，给你——与其说给你，不如说给你和你的 Claude——做审查，告诉你实现是否符合行业标准、哪里是外行看不到的坑。

直到初期用户落地、真实支付发生、迭代方向开始明确，服务器运营、SEO、营销和销售管道要跑起来，更多专业人才才按需进场。也许是工程师接替创始人的技术工作，也许是 marketing、sales、HR 和 management，也许是一个专门负责融资的人，让创始人把精力移到市场占有率与团队供血上。

需求在这个时代是多变的，而且经常需要并行验证。因此创始人周围的创业池子比固定编制更重要：里面可以有技术人员，也可以有各行业掌握真实需求的人，需要谁就把谁接进来。除非你要做的是特别特别远大的理想，比如造一个拟人机器人并干掉所有竞争者，一般来说，验证需求并不需要先养一支技术团队。

六、三方都理性，沙滩中央却挤满了

说得刻薄一点，讲故事的这些创业者其实也在做世间所有生意都做的事：信息差。利用投资者对技术和行业的信息差，换取一笔高额投资。好一点的项目还有点盼头，能跑到 A 轮、B 轮；坏一点的项目遇上信息差太大的投资人，往往就是颗粒无收。整个投资体验也非常差：投资人不懂他们在做什么，他们自己也不懂未来在哪里，最后一起被升级的大模型碾碎。

可如果只怪创业者，又太简单了。投资人理性地按幂律买故事，因为一百中一对他的基金最优；创始人理性地讲投资人愿意买的故事，因为不这么讲就拿不到维持传统团队的资金；人才也理性地涌进最热门、融资最多、履历最好看的叙事，因为那里的工资、期权和下一份工作都更确定。

三方各自在玩一场理性的局，合在一起，却可能得到集体利益的最小化。

就像一片很长的海滩。每个卖冰淇淋的摊主都想让自己离最多客人更近，于是一个接一个往沙滩正中央搬。最早来的几个可能都赚到了钱；后来所有摊子挤在中心，边缘的客人懒得走，中心的客人还没有摊子多。每个人都在追求个体利益最大化，最后沙滩上却没有新增多少生意，只多了一排彼此分流的摊位。

美国是一个崇尚自由的个人主义社会，我们不去过多评判这件事。我更关心的是：既然 AI 已经把生产方式改了，创业者能不能换一种更符合新生产方式的活法。

七、我们摸索出来的路

我们的出发点很简单：需求是自由的、可以并行；技术团队是按需的，很多早期实现可以先由 Claude 和 Codex 承担。于是由一个人负责需求，技术按人的空闲时间接入，或者先由创始人自己完成验证。

需求必须对接真实行业里的真实工作流。先用 AI 把工作复现出来，再顺手解决生产力超级盈余下已经很便宜的小问题：Word、Excel 可以自动读取，图片可以 OCR，散落的工作尽量集成在一个地方，让数据先跑起来，然后看看哪里真的值得继续。

但对接行业的人必须真的懂行。他手里要连着真实需求，讲得清上下游、各类细节和隐秘的潜规则。人是有惯性的，个人习惯尚且难改，行业习惯更牵着一串利益，改变如同刮骨疗毒，少有如关羽一样的行业，况且他刮骨的时候也是装逼为多，也不知道刮了是不是就变好。

技术人员可以在需求负责人已经用 Figma 或 Claude 画完原型、把工作流说清楚以后进场。我们把这种需求端与执行端按项目焊在一起的方式，叫作“如律所一般的组织”：懂行业、握客户的人负责挖需求和结果，能交付的人按需接入并为实现负责。

创始人在这个时代更像演唱会的指挥家：哪里缺什么，就把对应的资源整合进来。如果未来 agent 真能驱动市场，也许 marketing 都可以砍掉；但至少现在，需求要人去挖，投资要人去找，市场和客户仍要人来驱动。

这种外包式、池化的工作方式，本身也在利用 AI 快速迭代形成的信息差：进入行业，拿到关键需求信息，利用小企业的敏捷性先做成更有优势的产品，再以 disruptive technology 的方式和业内老产品竞争，像小米当年打高价旗舰那样。

这条路也不是免费的。Bootstrap 式验证意味着创始人自己扛机会成本：可能很长一段时间没有工资，没有融资新闻带来的光环，也没有“大团队正在高速前进”的心理安慰。你用自己的时间换低烧钱率，用不确定的回报换继续 pivot 的自由。这份代价应该诚实写在账上。

八、不是庞大叙事，而是切实的一条路

我现在更相信的现代创业，不是先搭一支符合故事的庞大团队，再祈祷市场替它找到存在理由；而是谦逊地、不断向内向外探索：把假设做出来，让现实证伪它；有人支付，再往前一步；需要哪种专业性，再把哪种人接进来。

故事可以讲，但它应该是已经发生的证据向前延伸出来的故事，而不是逼着所有人替未来圆谎的故事。AI 真正带来的，不只是更快写代码，而是让创业者有机会在极低边际成本下，把“融资前必须先相信”改成“先做、先卖、再决定值不值得相信”。

不是先拥有一支公司，才有资格寻找需求。
是先找到真实支付，公司才开始有理由长出来。

你现在看的这个网站——29 个 demo、全站双语、旅程系统——就是两三个创始人加几个 Claude/Codex 账户做出来的，边际成本几乎为零。这就是这篇文章的实物证据。
